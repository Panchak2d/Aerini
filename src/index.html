Privacy
Flowo is 100% local-first.
All workflows and credentials are stored on your device only — nothing is sent to Flowo servers.

Nodes you configure (HTTP Request, AI Prompt, etc.) make requests directly from your machine to the services you specify. Flowo never sees or logs these requests.

Credentials are encrypted at rest using a device-local key.

Flowo v0.2.0

Automate anything, locally.

Flowo runs entirely on your machine — no accounts, no cloud, no limits. Build automations by connecting blocks together. Each block does one thing: fetch data, send a message, run a script, call an AI.

1
Add nodes from the sidebar
Click any block in the left panel to place it on the canvas. Start with a Trigger — it's what starts your workflow.
2
Connect them with wires
Drag the dot on the right of one block to the dot on the left of another. Double-click any block to configure it.
3
Run your workflow
Click Run in the top-right to test it instantly. Use Schedule Run to run it automatically in the background.
Tip: Use {{node_id.field}} in any config field to pass data between nodes.
